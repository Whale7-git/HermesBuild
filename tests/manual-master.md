# Hermes 真机主回归单

本表合并能力域，保留历版清单作为历史证据；每版只另列增量。旧清单没有回执的项目不得转记为通过。
环境需记录：App版本/build、设备、iOS、输入法、实例、网络。状态：未测 / 通过 / 失败 / 阻塞。
本表是按需选取的真机用例库，不是每次提交或发版的必跑清单，也不是自动发布门禁。只执行与本次改动相关的项目；没有设备证据时保持“未测”，不得沿用其他版本的结果。
每项包含的反例也须执行；只做其中一半应写部分完成。时间为安排建议，不是测试通过条件。
