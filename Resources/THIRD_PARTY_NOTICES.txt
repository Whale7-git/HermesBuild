  Original MIT license retained as Vendor/Textual/LICENSE.
  The upstream file digests of the copy are recorded in
  Vendor/Textual/UPSTREAM-SHA256.json, so a local edit can be told apart from
  an upstream change.

  Local modifications (full rationale in Vendor/Textual/HERMES-PATCHES.md):
    1. Package.swift drops the upstream-only snapshot test target and its
       dependency; the library sources and resources are unchanged in scope.
    2. StructuredText.swift adds init(attributedString:deferCodeHighlightingAfter:)
       so prepared Markdown skips a UI-thread parse.
    3. BlockContent.swift makes blocks Equatable so unchanged bodies are skipped.
    4. CodeBlock.swift defers Prism highlighting for the active streaming tail.
    5. WithAttachments.swift moves the generic view's observable model out of the
       view and discards cancelled or superseded resolves.
    6. BlockVStack.swift shares real child measurements within one layout cache
       generation and invalidates reuse on environment/content changes.
    7. HighlightedTextFragment.swift / CodeTokenizer.swift key highlight work by
       input plus language, reject cancelled or superseded generations, and allow
       one retained result per mounted fragment.
    8. New source-local helpers BlockMeasurementCache.swift and
       TokenizationWork.swift hold the measurement-cache and publication logic.
    9. Selection interaction files (UITextInteractionView, TextSelectionInteraction,
       UIKitTextSelectionInteraction, UIKitTextInteractionOverlay, AppKit peer,
       TextSelectionLayoutUpdater, TextSelectionUpdateRelay) forward text menu
       actions and coalesce selection delivery; see HERMES-PATCHES.md.
   10. TextFragment/NativeSelectableText opt-in for native text views, described
       in the build35 section of HERMES-PATCHES.md.

  These modifications are distributed under the same MIT license as upstream.
  No binaries and no newly fetched runtime dependencies were added.
